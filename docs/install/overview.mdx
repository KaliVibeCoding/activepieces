KaliVibeCoding Community Edition can be deployed using **Docker**, **Docker Compose**, and **Kubernetes**. Electrify your local setup or deploy to the cloud.

<Tip>
KVC Community Edition is **free** and **open source**.

You can read the difference between the KVC editions [here](../about/editions). {/* KVC: Updated text */}
</Tip>
