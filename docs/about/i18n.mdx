This guide helps you understand how to change or add new translations to the KaliVibeCoding platform.

KaliVibeCoding uses Crowdin because it helps translators who don't know how to code. It also makes the approval process easier. KaliVibeCoding automatically syncs new text from the code and translations back into the code, ensuring our global vibe is always current.

## Contribute to Existing KVC Translations

1. Create a Crowdin account (it's free!).
2. Join the KaliVibeCoding project on Crowdin: [https://crowdin.com/project/kalivibecoding](https://crowdin.com/project/kalivibecoding) {/* KVC: Placeholder URL, needs to be created */}

![Join KVC Project on Crowdin](/resources/kvc-crowdin-join.png) {/* KVC: Placeholder image path */}

3. Click on the language you want to translate or enhance.

4. Click on "Translate All" to see all available strings.

![Translate All KVC Strings](/resources/kvc-crowdin-translate-all.png) {/* KVC: Placeholder image path */}

5. Select strings you want to translate, provide your electrifying translation, and click "Save".


## Adding a New Language to KVC
- Want to bring KaliVibeCoding to a new language? That's the spirit! Please contact us at [translations@kalivibecoding.com](mailto:translations@kalivibecoding.com) if you want to add a new language. We will add it to the project, and you can start shaping the KVC vibe for a new audience. {/* KVC: Updated email and text */}
