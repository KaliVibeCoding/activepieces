KaliVibeCoding's **core** is released as open source under the [MIT license](https://github.com/KaliVibeCoding/kalivibecoding/blob/main/LICENSE) and enterprise / cloud editions features are released under [KVC Commercial License](https://github.com/KaliVibeCoding/kalivibecoding/blob/main/packages/ee/LICENSE). {/* KVC: Updated names and links */}

The MIT license is a permissive license that grants users the freedom to use, modify, or distribute the software without any significant restrictions. The only requirement is that you include the license notice along with the software when distributing it. This is the KVC way – open, yet powerful.

Using the enterprise features (under the packages/ee and packages/server/api/src/app/ee folder) with a self-hosted instance requires a KaliVibeCoding license. If you are looking to unlock the full KVC spectrum, contact us at [sales@kalivibecoding.com](mailto:sales@kalivibecoding.com). {/* KVC: Updated name and email */}

**Benefits of KVC's Dual Licensing Approach** {/* KVC: Updated title */}

- **Transparency** - Everyone can see what we are doing and contribute to the project.
- **Clarity** - Everyone can see what the difference is between the open source and commercial versions of our software.
- **Audit** - Everyone can audit our code and see what we are doing.
- **Faster Development** - We can develop faster and more efficiently.
